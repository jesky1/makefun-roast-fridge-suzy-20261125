One original one-line roast of my own fridge: its light died years ago, so every midnight snack has become a trust exercise with a container from last Tuesday. Specific detail, twist at the end, reads cleanly aloud.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+) writes the single line to `/output/entry.txt`. `test.mjs` checks the competition gate (1–200 characters, one line, not blank) and that two runs produce identical text:

```sh
node --test test.mjs
```
